# Pesquisa de Satisfação - TudoWeb

## Descrição

Projeto desenvolvido em Python para realizar uma pesquisa de satisfação sobre o atendimento da empresa TudoWeb.

O sistema coleta informações de 50 entrevistados e registra suas opiniões sobre o atendimento recebido, trazendo ao fim da coleta um resumo entre opiniões ótimas e péssimas.

## Funcionalidades

- Cadastro de nome do entrevistado
- Cadastro da idade
- Registro da opinião sobre o atendimento
- Contabilização das respostas "Excelente"
- Contabilização das respostas "Ruim"
- Exibição do resultado final da pesquisa; contagem.

## Tecnologias Utilizadas

- Python

## Opções Disponíveis

| Código | Opinião |
|---------|----------|
| 1 | Excelente |
| 2 | Bom |
| 3 | Ruim |

## Exemplo de Uso

```text
Entrevistado 1

Nome: João
Idade: 25

Opinião sobre o atendimento:
1 - EXCELENTE
2 - BOM
3 - RUIM

Digite sua opção: 1
```

## Exemplo de Resultado

```text
===== RESULTADO DA PESQUISA =====
Quantidade de respostas EXCELENTE: 20
Quantidade de respostas RUIM: 5
```
